# 초기 MVP 개발 일정

이 문서는 현재 합의된 프로젝트 목표 일정을 관리한다.

아래 날짜는 진행 방향과 협업 시점을 맞추기 위한 목표일이다. 무조건 완료해야 하는 강제 마감으로 해석하지 않는다. Agent는 일정만을 이유로 요구 범위를 독단적으로 축소하거나 품질·검증 기준을 낮추지 않으며, 진행 상황과 위험을 사실대로 보고한다.

| 목표 완료일 | 대상 | 완료 목표 |
|---|---|---|
| 2026년 11월 1일 | Module 1 | 초기 MVP 시뮬레이션 구현 완료 |
| 2026년 11월 4일 | Module 2 | 초기 MVP 데이터 처리 및 피처 엔지니어링 구현 완료 |
| 2026년 11월 6일 | Module 3+4 | 초기 MVP 수요 예측 및 동적 배차 구현 완료 |

- 각 목표일에는 해당 모듈의 초기 MVP 기능과 필요한 문서 및 테스트를 함께 확인한다.
- 뒤 모듈이 사용할 공개 입력·출력 형식은 가능한 범위에서 목표일 전에 공유한다.
- 2026년 11월 6일 이후의 통합, 고도화, 실험 및 발표 일정은 현재 확정하지 않는다.
- 이후 일정은 초기 MVP 진행 상황을 확인한 뒤 팀에서 별도로 협의한다.
- 일정 변경은 이 문서에서 관리하고 `AGENTS.md`에 날짜를 중복 기록하지 않는다.
